## 치트·편의 기능

| 조작 | 기능 |
|---|---|
| SELECT를 누른 채 START | 별도 치트 옵션 페이지 열기 |
| 치트 메뉴에서 ←→ / B·X·START | 값 변경 / 닫기 |
| SELECT+Y | 아군 전원 HP·MP 완전 회복 및 상태이상 해제 |
| X → 시스템 → 세이브 | 어디서나 저장. 이 기능은 항상 켜짐 |

| 치트 항목 | 선택값·효과 |
|---|---|
| 일격필살 | 끔/켬. 적에게 주는 피해를 대상의 현재 HP로 변경 |
| 무적 | 끔/켬. **실제 효과는 받는 피해를 30으로 나누는 것** |
| 경험치 / 돈 | 각각 1·3·10·30배 |
| 인카운터 | 보통·절반 |
| 시각 | 게임 안의 날짜·시각 수정 |

시각 편집은 ←→로 년·월·일·시·분을 고르고 L/R로 값을 줄이거나 늘립니다. **A를 눌러야 시계에 저장**되며 그대로 나가면 반영되지 않습니다. 연도 범위는 2000~2099입니다.

치트 설정은 SRAM에 보관되어 재시작해도 유지됩니다. START만 누르면 원래 환경설정이 열립니다. 전투 등 설정 화면을 열 수 없는 상황에서 조합키를 누르면 다음 START에서 치트 페이지가 한 번 열릴 수 있으며 닫으면 정상으로 돌아갑니다.

## 적용 방법

1. 압축을 푼 무수정 원본의 크기·MD5·CRC32 또는 SHA-256이 위 표와 일치하는지 확인합니다.
2. 아래 해당 패치를 원본에 **한 번만** 적용하고 결과를 별도 파일로 저장합니다.
3. 적용 후 결과 크기와 체크섬을 다음 표와 대조합니다.

위 원본에는 512바이트 외부 복사기 헤더가 없습니다. `.smc`/`.sfc` 확장자만으로 헤더 여부를 판단하지 말고 파일 크기·해시를 확인하세요.

xdelta3 사용 예시(모든 경로는 큰따옴표로 묶습니다):

```text
xdelta3 -d -s "Daikaijuu Monogatari II (Japan).sfc" "SFC_DaikaijuuMonogatari2_KR_v0.9.8_wip121_260908.xdelta" "SFC_DaikaijuuMonogatari2_KR_v0.9.8_wip121_260908.sfc"
```

여러 패치가 있을 때는 사용할 변형이나 형식 **하나만** 선택합니다. IPS와 xdelta는 같은 결과를 만드는 대안입니다. IPS를 사용할 때도 원본 해시를 먼저 확인합니다.

이미 한글화된 ROM에 덧씌우지 않습니다. 원본과 기존 저장 파일은 백업하고, 저장 호환성은 아래 기존 안내의 해당 버전 설명을 따릅니다. 버전이 다른 즉시저장 대신 게임 내 이어하기를 사용하세요.

xdelta 또는 IPS 중 하나만 적용한다. 결과 ROM 옆에 동일 이름의 IPS를 두면 일부 에뮬레이터가 자동 적용할 수 있으므로 패치 파일은 별도 폴더에 보관한다. 현재 GitHub에는 개인 SRAM이나 ROM이 포함되어 있지 않다.
